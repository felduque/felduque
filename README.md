# Hola, soy Juan Felipe Duque 👋

### Desarrollador Full Stack · Mobile · E-commerce · ERP

📍 Medellín, Colombia

Soy desarrollador Full Stack con más de 4 años de experiencia creando aplicaciones **web, móviles y cloud-native** para comercio electrónico y entornos de alta demanda. Me enfoco en construir soluciones escalables que automaticen procesos y generen valor real para el negocio.

## 🚀 Lo que hago

- 📱 **Apps móviles multiplataforma** para iOS y Android con React Native CLI (React), TypeScript y JavaScript
- ⚡ **Comunicación en tiempo real** con WebSockets y APIs REST en escenarios de alta demanda
- 🛒 **Automatización de e-commerce** con Amazon SP-API, Node.js y TypeScript: inventario, transacciones, devoluciones y rentabilidad
- 🧩 **Módulos en Odoo** (Python, XML, QWeb, PostgreSQL) para e-commerce y gestión interna: portal de soporte, finanzas e inventario
- ☁️ **Soluciones cloud-native** en Google Cloud Platform con procesamiento asíncrono mediante Cloud Tasks
- 🎨 **Frontends web** en Angular 18+ con TypeScript, RxJS, HTML5, TailwindCSS, SASS/SCSS y pruebas unitarias con Jest
